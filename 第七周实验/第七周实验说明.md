# 第七周实验说明：训练 LoRA 并比较微调前后的回答

## 这周在做什么实验

本周使用第六周清洗的学习伴侣数据，在本地 `Qwen2.5-0.5B-Instruct` 上完成一次真正的 LoRA 监督微调，并把微调前后的模型放在相同问题和指标下比较。主线是“准备数据 → 选择超参数 → 训练并保存适配器 → 定量与定性评估”。与第六周只验证适配器可加载不同，本周会计算 loss、反向传播并更新 LoRA 参数。

## 实验一：把 JSONL 变成训练张量

`classroom/data_utils.py` 把每条 `instruction`、`input`、`output` 拼成“### 指令 / ### 输入 / ### 回答”的统一文本，并用第六周基座模型的分词器编码。`input_ids` 包含提示和回答，使模型能读到问题；`labels` 把提示部分设为 `-100`，只在回答 token 和结尾 EOS 上计算交叉熵。不同长度样本在每个 batch 内动态 padding，padding 部分同样不参与 loss。

`step01_prepare_data.py` 读取训练与验证 JSONL，检查样本长度、截断风险、任务类别和 DataLoader。指导书示例使用 448 条训练、50 条验证，检查用 `batch_size=2` 时每轮 224 个训练 batch、25 个验证 batch，最长样本 533 token，低于 `max_length=576`。这些数字来自指导书的示例数据；换数据后应以脚本实际报告为准。

## 实验二：选择 LoRA 超参数

可选的 `search_hyperparams.py` 使用 Optuna TPE 搜索学习率、batch size 和 LoRA 秩 `r`。默认每个 trial 从同一基座重新开始，用训练集前 128 条训练 3 轮，再以完整验证集的 loss 比较参数组合。指导书展示 10 组试验、前 3 组初始探索，示例最佳组合约为 `lr=3.6882e-4`、`batch_size=1`、`r=16`。这只是一次搜索的结果，换数据或环境后不保证相同。

**指导书与当前代码有一处差异：**指导书后续训练示例采用上述最佳组合；当前 `step02_train_lora.py` 的命令行默认值却是 `lr=0.0004600214305049643`、`batch_size=2`、`r=16`。如果要复现指导书展示的训练配置，需要显式传入 `--lr 0.0003688213144727346 --batch-size 1 --r 16`；直接运行无参数脚本会使用代码默认值。

## 实验三：手写训练循环并保存最佳适配器

`step02_train_lora.py` 加载第六周的 0.5B 基座，冻结原权重，把 LoRA 挂到 `q_proj` 和 `v_proj`。每个 batch 依次执行前向、回答区交叉熵、清空梯度、反向传播和优化器更新；每轮结束计算验证 loss。默认共训练 6 轮，只把验证 loss 最低时的适配器保存到 `adapters/qwen05b-learning-companion-lora-finetuned/`，同时画出 `assets/loss_curve.png` 并生成训练报告。

指导书示例中的训练 loss 持续下降，而验证 loss 在第 3 轮最低、此后回升，因此保存第 3 轮的适配器。这说明继续拟合训练样本可能增加过拟合风险；实际最佳轮次应由自己的验证曲线决定。

## 实验四：定量和定性比较

`step03_evaluate.py` 在同一验证集上比较基座与微调模型的回答区 loss、困惑度，以及前 20 条生成回答的 ROUGE-L。困惑度为 `exp(loss)`，越低表示参考回答在模型下越容易被预测；ROUGE-L 衡量生成文本与参考答案的最长公共子序列重合度。指导书示例中，困惑度由 `34.669` 降到 `15.924`，ROUGE-L F1 由 `0.1888` 升到 `0.2416`。这说明模型更贴近该验证集的表达方式，仍需另查事实正确性。

`step04_qualitative_chat.py` 接受终端问题，分别打印基座与微调模型的回答、生成 token 数及停止原因。指导书用 ReAct 和 PagedAttention 问题展示领域适应效果；比较时要看概念是否正确、是否跑题、教学风格是否合适，而不只看回答长度或是否触发 EOS。

## 建议运行顺序与验收材料

先确认第六周的本地基座模型和 `data/train.jsonl`、`data/validation.jsonl` 已准备好。在 `第七周实验` 目录运行：

```text
python -s classroom/check_environment.py
python -s classroom/step01_prepare_data.py
python -s classroom/step02_train_lora.py --lr 0.0003688213144727346 --batch-size 1 --r 16
python -s classroom/step03_evaluate.py
python -s classroom/step04_qualitative_chat.py
```

若要自己搜索超参数，先安装 `optuna`，在训练前运行 `search_hyperparams.py --trials 10 --limit 128 --epochs 3 --n-startup-trials 3`，再把得到的参数传给训练脚本。检查 `outputs/` 中的数据、训练和评估报告，`assets/loss_curve.png` 与保存的适配器；以各脚本实际输出的 `PASS` 和验证指标作为验收依据。当前目录只有代码和指导书，未包含第六周的数据、基座权重或训练完成的适配器，因此指导书数值属于示例结果。
