# 第二周实验说明：实现自注意力并探索 BERT 与 GPT-2

## 这周在做什么实验

本周实验围绕 Transformer 的核心机制展开。先用 PyTorch 从零实现单头和多头自注意力，检查计算过程与官方实现是否一致；再把自实现的注意力接入一个小型句子补全分类器；最后用 Hugging Face Transformers 加载预训练的 BERT-base 和 GPT-2，观察两者的网络结构和预测方式。RNN、LSTM 用于说明序列模型的发展背景，本周没有实现或训练它们。

完成后，应能解释 Q、K、V 和注意力权重，读懂张量形状，验证多头实现的正确性，并区分 BERT 的双向填词与 GPT-2 的从左到右续写。

## 实验一：从零实现单头和多头自注意力

`classroom/attention.py` 定义了两个 PyTorch 网络层。单头注意力把同一输入 `X` 投影为 `Q`、`K`、`V`，计算

```text
Scores  = Q Kᵀ / √d
Weights = softmax(Scores)
Context = Weights V
```

其中 `Scores[i,j]` 衡量位置 `i` 对位置 `j` 的匹配程度；`Weights` 的每一行非负且总和为 1；`Context` 是各位置 Value 向量的加权和。`step01_single_head_attention.py` 使用固定随机种子和形状为 `[1,4,8]` 的随机输入，展示权重矩阵、Value 向量和第一个位置的 Context，并用手工加权结果核对模型输出。四个中文词只是位置标签，真正的输入是随机向量，因此这些权重没有训练后的语言含义。

多头版本把维度 `D=8` 拆为 `H=2` 个头，每头维度 `d_h=4`。每个头独立计算 `[4,4]` 的注意力权重，再把各头 Context 拼回 `[1,4,8]`，经过输出投影融合。`step02_multi_head_attention.py` 逐项打印拆头前后的 Q、各头 Context、合并结果和最终输出。这里的重点是理解 `[B,L,D] → [B,H,L,d_h] → [B,L,D]` 的形状变化。

## 实验二：验证实现并观察注意力

`step03_validate_and_visualize.py` 把自实现层的参数复制给 `torch.nn.MultiheadAttention`，让两者处理相同输入，然后比较输出和权重。这是对拆头、缩放、矩阵运算、合并与输出投影的数值验证。脚本还检查：每行权重之和接近 1；重复推理结果一致；参数能收到梯度；改变一个输入位置会影响其他位置的输出。

验收阈值为行和误差小于 `1e-6`，官方实现的输出和权重最大误差均小于 `1e-5`。脚本生成 `assets/attention_heatmap.png` 供观察两个头关注的位置；热力图本身不构成正确性证明。

## 实验三：用自实现注意力做句子补全

`completion_data.py` 定义一个封闭的五分类任务：输入四个空格分隔的中文词，从“学习、下雨、健康、阅读、回家”中选择第五个词。数据共 50 条，每类 10 条。`completion_model.py` 在自实现多头注意力前加入词嵌入和位置嵌入，在其后加入残差连接、归一化、前馈层和分类头；分类头把最后一个输入位置的表示映射为五个 logits，再用 softmax 得到候选词概率。

`tools/train_toy_completion.py` 在 CPU 上训练 500 轮并保存 `models/toy_attention_completion.pt`。`step04_sentence_completion.py` 加载该权重，输出五组固定示例的预测概率，并生成 `assets/completion_probabilities.png`。`interactive_completion.py` 可供手工输入四词提示。注意，这五组固定验收示例取自训练数据，只能说明模型学会了这个封闭任务，不能据此认定它能处理任意中文句子。

**结果应如何理解：**指导书展示训练集准确率达到 `1.000`，五个固定示例也全部预测正确。五个示例均来自训练集，没有独立测试集，因此这些数字只证明模型拟合了已有样本，不能衡量它对新句子的泛化能力。手工输入新词时，词表外的词还会统一映射为 `[UNK]`。

## 实验四：加载并探索预训练模型

`step05_download_models.py` 下载或检查两个固定版本的模型：`google-bert/bert-base-uncased` 和 `openai-community/gpt2`。配置、分词器和权重放在 `models/` 下；后续探索脚本只从本地读取。这一步获取的是已经预训练好的权重，本实验没有从零训练 BERT 或 GPT-2。

| 模型 | 课堂任务 | 主要结构 | 读取哪个位置的输出 |
| --- | --- | --- | --- |
| BERT-base | 预测英文句子中的 `[MASK]` | 12 层双向 Encoder，隐藏维 768，12 个注意力头；MLM 与 NSP 两个预训练任务头 | `[MASK]` 位置的 MLM logits |
| GPT-2 | 预测下一个 token 并续写英文 | 12 个带因果注意力的 Transformer Block，隐藏维 768，12 个注意力头；语言模型头 | 最后一个输入位置的 logits |

`step06_explore_bert.py` 对 “The capital of France is [MASK].” 做前向推理，检查分词、嵌入、12 层 Encoder、MLM 和 NSP 输出，并保存 `outputs/bert_architecture.txt`。BERT 的双向注意力允许 `[MASK]` 同时利用左右文；本例的 NSP 输出只用于观察架构，不用于填词。

`step07_explore_gpt2.py` 对 “Artificial intelligence can help students” 做前向推理，检查 token 与位置嵌入、12 个 Block 和词表 logits，然后反复选择下一个 token 生成续写，并保存 `outputs/gpt2_architecture.txt`。GPT-2 的因果注意力只能利用当前位置及其左侧内容。它在这里是英文续写模型，并非多轮聊天模型；自实现注意力部分也没有另做因果 mask 实验。

## 建议运行顺序与验收材料

在 `第二周实验` 目录下，先激活第一周的 `llm-course` Conda 环境，并按指导书安装 `matplotlib==3.10.5`。然后依次运行：

```text
python -s classroom/step01_single_head_attention.py
python -s classroom/step02_multi_head_attention.py
python -s classroom/step03_validate_and_visualize.py
python -s classroom/tools/train_toy_completion.py
python -s classroom/step04_sentence_completion.py
python -s classroom/step05_download_models.py
python -s classroom/step06_explore_bert.py
python -s classroom/step07_explore_gpt2.py
```

终端出现 `checkpoint: PASS` 表示对应脚本的内置检查通过。重点保存或检查 `outputs/` 中的 JSON 结果与架构文本、`assets/` 中的热力图和概率图，以及 `models/` 中的微型分类器权重和两个预训练模型文件。BERT、GPT-2 的输出依赖本地模型文件；首次下载需要网络，权重合计约 946 MiB，具体大小以实际文件为准。

## 一句话总结

这周不是“训练一个大语言模型”，而是通过**手写注意力、数值验证、小任务训练、预训练模型结构观察**四个环节，理解 Transformer 如何在序列位置之间传递信息，以及 BERT 和 GPT-2 如何把这种机制用于不同的文本预测任务。
